不必逐个输入配置，可以直接把宝可梦和队伍导入计算器。计算会直接使用你实际在用的配置。

支持的格式

粘贴PokePaste链接、VR Pastes链接，或者配置和队伍的Showdown文本。格式会自动识别。如果是链接，Paste的标题也会作为队伍名称导入。

导入窗口。用SP和EV指定文本中能力分配的单位。

窗口下方的SP或EV用来指定文本中的分配是能力点数还是EV。

导入1只宝可梦

在一对一中，每个配置上方的导入会替换那一边的宝可梦。在一对多和多对一中，配置上方的导入会在队伍不足6只时添加宝可梦。

配置上方的保存配置、导入和导出。

导入整支队伍

队伍组件中的导入会把包含招式、持有物和SP的整支队伍作为新队伍加载。

队伍组件在队伍标签页中。

带有队伍表、导入、导出Paste和删除的队伍组件。

导入对手

在一对多和多对一中，在对手中选择我的列表，点击导入把宝可梦加入列表。可以导入任意数量，用整个环境或威胁列表来测试你的队伍。

对手和导入在卡片列表之后的管理中。

导入和全部删除只在选择我的列表时显示。

从Paste和队伍页面

Paste和队伍页面中的所有队伍都可以作为我的队伍或对手直接加载到计算器中。请参阅队伍页面和导出与分享页面。
