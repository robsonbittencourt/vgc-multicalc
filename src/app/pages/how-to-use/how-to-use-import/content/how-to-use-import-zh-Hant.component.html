不必逐個輸入配置，可以直接把寶可夢和隊伍匯入計算器。計算會直接使用你實際在用的配置。

支援的格式

貼上PokePaste連結、VR Pastes連結，或者配置和隊伍的Showdown文字。格式會自動識別。如果是連結，Paste的標題也會作為隊伍名稱匯入。

匯入視窗。用SP和EV指定文字中能力分配的單位。

視窗下方的SP或EV用來指定文字中的分配是能力點數還是EV。

匯入1只寶可夢

在一對一中，每個配置上方的匯入會替換那一邊的寶可夢。在一對多和多對一中，配置上方的匯入會在隊伍不足6只時新增寶可夢。

配置上方的儲存配置、匯入和匯出。

匯入整支隊伍

隊伍元件中的匯入會把包含招式、持有物和SP的整支隊伍作為新隊伍載入。

隊伍元件在隊伍標籤頁中。

帶有隊伍表、匯入、匯出Paste和刪除的隊伍元件。

匯入對手

在一對多和多對一中，在對手中選擇我的列表，點選匯入把寶可夢加入列表。可以匯入任意數量，用整個環境或威脅列表來測試你的隊伍。

對手和匯入在卡片列表之後的管理中。

匯入和全部刪除只在選擇我的列表時顯示。

從Paste和隊伍頁面

Paste和隊伍頁面中的所有隊伍都可以作為我的隊伍或對手直接載入到計算器中。請參閱隊伍頁面和匯出與分享頁面。
