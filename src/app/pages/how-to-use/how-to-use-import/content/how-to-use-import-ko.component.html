세트를 하나씩 입력하는 대신 포켓몬과 팀을 계산기로 가져올 수 있습니다. 계산에는 실제로 쓰는 세트가 그대로 사용됩니다.

지원하는 형식

PokePaste 링크, VR Pastes 링크, 또는 세트나 팀의 Showdown 텍스트를 붙여 넣으세요. 형식은 자동으로 판별됩니다. 링크라면 Paste의 제목도 팀 이름으로 가져옵니다.

가져오기 창. SP와 EV로 텍스트 속 분배의 단위를 지정합니다.

창 아래쪽의 SP 또는 EV로 텍스트 속 분배가 능력 포인트인지 EV인지 지정합니다.

포켓몬 1마리 가져오기

1 vs 1에서는 각 빌드 위의 가져오기가 그쪽 포켓몬을 바꿉니다. 팀 vs 다수와 다수 vs 팀에서는 빌드 위의 가져오기가 팀이 6마리 미만일 때 포켓몬을 추가합니다.

빌드 위의 세트 저장, 가져오기, 내보내기.

팀 전체 가져오기

팀 위젯의 가져오기는 기술, 도구, SP를 포함한 팀 전체를 새 팀으로 불러옵니다.

팀 위젯은 팀 탭입니다.

팀 리스트, 가져오기, Paste 내보내기, 삭제가 있는 팀 위젯.

상대 가져오기

팀 vs 다수와 다수 vs 팀에서는 상대에서 내 리스트를 고르고 가져오기를 클릭해 포켓몬을 리스트에 추가합니다. 원하는 만큼 가져올 수 있으므로 환경 전체나 위협 리스트에 대해 내 팀을 시험할 수 있습니다.

상대와 가져오기는 카드 리스트 뒤의 관리에 있습니다.

가져오기와 모두 삭제는 내 리스트일 때만 표시됩니다.

Paste와 팀 페이지에서

Paste와 팀 페이지의 모든 팀은 내 팀 또는 상대로 바로 계산기에 불러올 수 있습니다. 팀 페이지와 내보내기와 공유 페이지를 참고하세요.
