セットを1つずつ入力する代わりに、ポケモンやチームを計算機に取り込めます。計算には実際に使っているセットがそのまま使われます。

対応している形式

PokePasteのリンク、VR Pastesのリンク、またはセットやチームのShowdownテキストを貼り付けます。形式は自動で判別されます。リンクの場合は、Pasteのタイトルもチーム名として取り込まれます。

インポート画面。SPとEVでテキスト内の振り方の単位を指定します。

画面下部のSPまたはEVで、テキスト内の振り方が能力ポイントかEVかを指定します。

ポケモンを1匹インポート

1対1では、各ビルドの上のインポートでその側のポケモンを置き換えます。チーム対多数と多数対チームでは、ビルドの上のインポートで、チームが6匹未満のときにポケモンを追加します。

ビルドの上のセットを保存、インポート、エクスポート。

チーム全体をインポート

チームウィジェットのインポートで、技、持ち物、SPを含むチーム全体を新しいチームとして読み込みます。

チームのウィジェットはチームタブです。

チームリスト、インポート、Paste出力、削除があるチームのウィジェット。

相手をインポート

チーム対多数と多数対チームでは、相手でマイリストを選び、インポートをクリックしてポケモンをリストに追加します。好きなだけインポートできるので、環境全体や脅威のリストに対して自分のチームを試せます。

相手とインポートは、カードのリストの後の管理にあります。

インポートとすべて削除は、マイリストのときだけ表示されます。

Pasteやチームページから

Pasteとチームページのすべてのチームは、自分のチームまたは相手として、そのまま計算機に読み込めます。チームページとエクスポートと共有のページを参照してください。
