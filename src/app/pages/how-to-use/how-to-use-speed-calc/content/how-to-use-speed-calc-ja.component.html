素早さ計算は、環境のポケモン、相手、または自分のチームに対して、自分のポケモンが行動順のどこにいるかを表示します。行動順は多くの試合を左右し、ほとんどの振り方は素早さから決まります。

素早さリスト

ポケモンを選択した、レギュレーションM-Cの素早さリスト。

リストはすべてのポケモンを遅い順から速い順に素早さの目盛りに並べ、自分のポケモンもその中に入ります。各スプライトの下には数値の根拠が表示されます：最小、最大、性格、その素早さを使うプレイヤーの割合、こだわりスカーフの振り方ならスカーフ、ブーストエナジーならブースト。同速は素早さが同じ2匹を示します。

実際の素早さ：あめのすいすいなどの特性、こだわりスカーフなどの持ち物、まひ、フィールドを適用し、能力値だけでなく対戦で使われる数値を表示します。

リストのポケモンをクリックすると、より速くで、そのポケモンより先に動くのに必要な最小の素早さSPを自分のポケモンに設定します。

絞り込み

絞り込みは補正タブにあります。

絞り込み、使用率上位、モード、ポケモン、チーム全体。
  • 絞り込み：Reg M-Cはレギュレーションのポケモン、相手は相手のリストを表示します。自分のチームを選ぶこともできます。
  • 使用率上位：レギュレーションを選んでいるとき、使用率上位の何匹をリストに入れるか。
  • モード：各ポケモンにどの素早さを表示するか：能力値と環境、能力値、環境、種族値。
  • ポケモン：ポケモンを1匹検索して、自分の素早さをそのポケモンのすべての振り方と比べます。
  • チーム全体：編集中のポケモンだけでなく、チームのすべてのポケモンをリストに入れます。

素早さ補正

リストの素早さを変える場所は2つあります。相手だけに効く相手の場と、両側に効くフィールドです。自分のポケモンは自分のビルドにも従います。

相手の場は素早さリストの右上にあります。は補正タブにあります。リストのすべての相手の素早さを変えます：

相手の素早さ補正、こごえるかぜ、まひ、こだわりスカーフ。
  • 素早さ補正：素早さのランク変化。
  • こごえるかぜ：こごえるかぜやエレキネットを受けた後のように、素早さ補正を-1にします。
  • まひ：素早さを半分にします。
  • こだわりスカーフ：相手がこだわりスカーフを持っているとして計算します。メガシンカするポケモンはメガストーンのままです。オフのときも、レギュレーションのリストには、スカーフで使われるポケモンについてスカーフの振り方とプレイヤーの割合がすでに表示されています。

フィールド

素早さ計算のフィールドには、自分のポケモンと相手の素早さを変えるものだけがあります。チームのウィジェットの下にあります。補正タブの相手の場の下にあります。

両側のおいかぜ、天気、エレキフィールド、トリックルーム。
  • おいかぜ：素早さを2倍にします。攻撃側なら自分のポケモン、守備側なら相手に効きます。
  • トリックルーム：リストを逆にし、遅いポケモンから先に動きます。
  • 天気とエレキフィールド：あめのすいすい、はれのようりょくそ、すなかき、ゆきかき、サーフテールなどの素早さの特性を発動させます。

素早さ分析

レギュレーションM-Cで選択したポケモンの素早さ分析。

リストのポケモンをクリックすると分析が表示されます。分析タブにあります。

  • 範囲：素早さの種族値、無補正の性格での範囲、上昇補正の性格とSP 32での最大値、トリックルーム向けのポケモンなら下降補正の性格とSP 0での最小値。
  • よく使われる素早さ：プレイヤーが最もよく使う素早さと、それぞれが同じポケモンの何%より速いか同速か。
  • 素早さの持ち物：こだわりスカーフ、パラドックスポケモンならブーストエナジーで届く素早さと、その持ち物を使うプレイヤーの割合。
  • 出典：統計はPokémon Showdown Bo3ラダーの全レートのデータです。
