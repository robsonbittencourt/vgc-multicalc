速度計算會顯示你的寶可夢在環境寶可夢、對手或你的隊伍中處於行動順序的什麼位置。行動順序左右著許多比賽，大多數分配也是從速度開始決定的。

速度列表

選中寶可夢的規則M-C速度列表。

列表把所有寶可夢按從慢到快排在速度刻度上，你的寶可夢也在其中。每個圖示下方會顯示數值的依據：最小、最大、性格、使用這個速度的玩家比例，講究圍巾的分配顯示圍巾，驅勁能量顯示驅勁。同速表示速度相同的2只寶可夢。

實際速度：套用雨天的悠游自如等特性、講究圍巾等持有物、麻痺和場地，顯示的不只是能力值，而是對戰中實際使用的數值。

點選列表中的寶可夢，比……更快會把你的寶可夢設為先於它行動所需的最少速度SP。

篩選

篩選在修正標籤頁中。

篩選、使用率前列、模式、寶可夢和我的整支隊伍。
  • 篩選：Reg M-C顯示規則中的寶可夢，對手顯示對手列表。也可以選擇你的隊伍。
  • 使用率前列：選擇規則時，列表中放入使用率前多少名的寶可夢。
  • 模式：每隻寶可夢顯示哪種速度：能力值和環境、能力值、環境、種族值。
  • 寶可夢：搜尋1只寶可夢，把你的速度和它的所有分配比較。
  • 我的整支隊伍：不只是正在編輯的寶可夢，把隊伍中所有寶可夢都放進列表。

速度修正

改變列表中速度的地方有兩處：只對對手生效的對手場地，以及對兩邊都生效的場地。你的寶可夢也會遵循你的配置。

對手場地在速度列表的右上方。在修正標籤頁中。它會改變列表中所有對手的速度：

對手的速度修正、冰凍之風、麻痺和講究圍巾。
  • 速度修正：速度的能力變化等級。
  • 冰凍之風：像受到冰凍之風或電網之後一樣，把速度修正設為-1。
  • 麻痺：速度減半。
  • 講究圍巾：計算時視為對手攜帶講究圍巾。會超級進化的寶可夢保留超級石。即使關閉，規則列表中也已經顯示了常帶圍巾的寶可夢的圍巾分配和玩家比例。

場地

速度計算的場地裡只有會改變你的寶可夢和對手速度的項目。它在隊伍元件下方。它在修正標籤頁的對手場地下方。

兩邊的順風、天氣、電氣場地和戲法空間。
  • 順風：速度加倍。攻擊方對你的寶可夢生效，防守方對對手生效。
  • 戲法空間：把列表反過來，慢的寶可夢先行動。
  • 天氣與電氣場地：發動雨天的悠游自如、晴天的葉綠素、撥沙、撥雪和衝浪之尾等速度特性。

速度分析

規則M-C中所選寶可夢的速度分析。

點選列表中的寶可夢就會顯示分析。它在分析標籤頁中。

  • 範圍：速度種族值、不影響能力的性格下的範圍、提高能力的性格加SP 32時的最大值，如果是戲法空間用的寶可夢，還有降低能力的性格加SP 0時的最小值。
  • 常用速度：玩家最常用的速度，以及每種速度比同種寶可夢中的百分之多少更快或同速。
  • 速度持有物：講究圍巾，以及悖謬寶可夢的驅勁能量能達到的速度和使用該持有物的玩家比例。
  • 來源：統計來自Pokémon Showdown Bo3天梯全分段的資料。
