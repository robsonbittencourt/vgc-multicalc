Exportez vos sets au format Showdown, partagez votre équipe en Paste ou remplissez la fiche d’équipe d’un tournoi.

Exporter un seul Pokémon

Exporter au-dessus du build donne le texte Showdown du Pokémon que vous modifiez, avec ses capacités, son objet, son talent, sa nature et ses SP. Cela fonctionne pour votre équipe et pour les adversaires.

Exporter, Combiner les dégâts et Supprimer au-dessus du build.

Exporter une équipe complète et créer un Paste

Exporter dans le widget Équipes ouvre la page Créer un Paste avec le texte Showdown de toute l’équipe. Copiez le texte, ou créez un Paste : une page avec les sprites, objets, capacités et répartitions de l’équipe, partagée par un lien. Créer un Paste dans l’en-tête ouvre la même page.

Exporter et Fiche d’équipe sont dans l’onglet Équipes, et Créer un Paste est dans le menu.

Création d’un Paste à partir de l’équipe championne de Francfort.
  • Nom de l’équipe et ID d’équipe : affichés sur le Paste.
  • Points de stats : SP ou EV, l’unité des répartitions dans le texte et dans le Paste.
  • Afficher les SP : désactivez-le pour partager l’équipe sans les répartitions.
  • Mot de passe : seules les personnes ayant le mot de passe peuvent ouvrir le Paste. Un mot de passe perdu ne peut pas être récupéré.

Quiconque ouvre un Paste peut charger l’équipe dans le calcul, comme sa propre équipe ou comme adversaires.

Fiche d’équipe

Fiche d’équipe dans le widget Équipes remplit la fiche d’équipe officielle d’un tournoi en PDF. Ajoutez vos données de joueur et votre catégorie d’âge, et choisissez les pages : Staff, OTS (fiche d’équipe ouverte) ou Les deux. Tous les champs sont facultatifs.

La fenêtre de la fiche d’équipe.

Exporter les adversaires et les calculs

Exporter dans l’en-tête des adversaires donne le texte Showdown de tous les Pokémon de la liste, pour partager une liste de menaces ou une partie du méta.

Exporter les calculs et Exporter dans l’en-tête des adversaires.

Exporter les calculs donne la description du calcul de chaque carte, une par ligne, prête à coller n’importe où.

Exporter et Exporter les calculs sont dans Gestion, après la liste des cartes.
