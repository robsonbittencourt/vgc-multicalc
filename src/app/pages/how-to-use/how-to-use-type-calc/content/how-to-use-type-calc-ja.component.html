タイプ計算は、チーム全体の攻撃面の相性と防御面の相性を表示し、どこが強くどこが弱いかを確認できます。

別のチームとの比較

自分のポケモンと、ボルチモア準優勝チームのポケモン。

単純なタイプ相性表と違い、チームの技と特性を使って計算します。ポケモンや技を変えるとすぐに更新されます。

2つ目のチーム：Ctrl（MacではCmd）を押しながらチームウィジェットの別のチームをクリックします。表には、タイプごとではなく、自分のポケモンとそのチームのポケモンの相性が表示されます。

2つ目のチーム：チームタブで、別のチームを自分のチームにドラッグします。表には、タイプごとではなく、自分のポケモンとそのチームのポケモンの相性が表示されます。

ふゆう、ふうせん、きもったま、かたやぶり、フェアリースキン、みずタイプへのフリーズドライなど、タイプ相性を変える特性や持ち物も計算に入ります。

攻撃面の相性

チームが各タイプにどう攻撃できるかを表示します：

  • こうかばつぐん：チームの技の少なくとも1つが弱点を突けるタイプ。
  • ポケモンごと：各ポケモンの技の、各タイプに対する最も高い相性。
  • 穴：チームが等倍以上で攻撃できないタイプ。
フランクフルト優勝チームの攻撃面の相性。

防御面の相性

各タイプがチームにどう攻撃してくるかを表示します：

  • 弱点：各ポケモンにこうかばつぐんのダメージを与えるタイプ。
  • 半減と無効：ポケモンが安全に交代で受けられるタイプ。
  • 弱点の合計と半減以下の合計：各タイプに弱い、または半減以下で受けられるポケモンの数。共通の弱点を見つけるのに役立ちます。
フランクフルト優勝チームの防御面の相性。

分析

相性のまとめです（分析タブにあります）：

  • 攻撃面：こうかばつぐんの攻撃が最も多いポケモン2匹と、いまひとつの攻撃が最も多いポケモン2匹。
  • 攻撃面のタイプ：チームが最も多くこうかばつぐんを取れるタイプと、最も多くいまひとつになるタイプ。
  • 防御面：半減と無効が最も多いポケモン2匹と、弱点が最も多いポケモン2匹。
  • 防御面のタイプ：チームが最も多く半減できるタイプと、最も弱いタイプ。
フランクフルト優勝チームの分析。
