屬性計算會顯示整支隊伍的攻擊相性和防守相性，讓你看清強項和弱項。

與另一支隊伍比較

你的寶可夢和巴爾的摩亞軍隊伍的寶可夢。

與簡單的屬性相性表不同，它會用隊伍的招式和特性來計算。改變寶可夢或招式會立即更新。

第二支隊伍：按住Ctrl（Mac上為Cmd）在隊伍元件中點選另一支隊伍。表格會顯示你的寶可夢與那支隊伍寶可夢之間的相性，而不是按屬性顯示。

第二支隊伍：在隊伍標籤頁中，把另一支隊伍拖到你的隊伍上。表格會顯示你的寶可夢與那支隊伍寶可夢之間的相性，而不是按屬性顯示。

飄浮、氣球、膽量、破格、妖精皮膚以及對水屬性的冷凍乾燥等改變屬性相性的特性和持有物也會計入。

攻擊相性

顯示隊伍能如何攻擊每種屬性：

  • 效果絕佳：隊伍中至少有1個招式能打出弱點的屬性。
  • 各寶可夢：每隻寶可夢的招式對每種屬性的最高相性。
  • 漏洞：隊伍無法以普通以上效果攻擊的屬性。
法蘭克福冠軍隊伍的攻擊相性。

防守相性

顯示每種屬性會如何攻擊你的隊伍：

  • 弱點：對每隻寶可夢造成效果絕佳傷害的屬性。
  • 抵抗與無效：寶可夢可以安全替換出來承受的屬性。
  • 弱點合計與抵抗合計：對每種屬性弱或能抵抗的寶可夢數量，有助於找出共同的弱點。
法蘭克福冠軍隊伍的防守相性。

分析

相性的總結（在分析標籤頁中）：

  • 攻擊面：效果絕佳攻擊最多的2只寶可夢，以及效果不好攻擊最多的2只寶可夢。
  • 攻擊面屬性：隊伍最多能打出效果絕佳的屬性，以及最多會效果不好的屬性。
  • 防守面：抵抗和無效最多的2只寶可夢，以及弱點最多的2只寶可夢。
  • 防守面屬性：隊伍最能抵抗的屬性和最弱的屬性。
法蘭克福冠軍隊伍的分析。
