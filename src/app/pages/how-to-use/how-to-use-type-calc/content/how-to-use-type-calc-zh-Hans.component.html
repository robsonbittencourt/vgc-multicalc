属性计算会显示整支队伍的攻击相性和防守相性，让你看清强项和弱项。

与另一支队伍比较

你的宝可梦和巴尔的摩亚军队伍的宝可梦。

与简单的属性相性表不同，它会用队伍的招式和特性来计算。改变宝可梦或招式会立即更新。

第二支队伍：按住Ctrl（Mac上为Cmd）在队伍组件中点击另一支队伍。表格会显示你的宝可梦与那支队伍宝可梦之间的相性，而不是按属性显示。

第二支队伍：在队伍标签页中，把另一支队伍拖到你的队伍上。表格会显示你的宝可梦与那支队伍宝可梦之间的相性，而不是按属性显示。

飘浮、气球、胆量、破格、妖精皮肤以及对水属性的冷冻干燥等改变属性相性的特性和持有物也会计入。

攻击相性

显示队伍能如何攻击每种属性：

  • 效果绝佳：队伍中至少有1个招式能打出弱点的属性。
  • 各宝可梦：每只宝可梦的招式对每种属性的最高相性。
  • 漏洞：队伍无法以普通以上效果攻击的属性。
法兰克福冠军队伍的攻击相性。

防守相性

显示每种属性会如何攻击你的队伍：

  • 弱点：对每只宝可梦造成效果绝佳伤害的属性。
  • 抵抗与无效：宝可梦可以安全替换出来承受的属性。
  • 弱点合计与抵抗合计：对每种属性弱或能抵抗的宝可梦数量，有助于找出共同的弱点。

分析

相性的总结（在分析标签页中）：

  • 攻击面：效果绝佳攻击最多的2只宝可梦，以及效果不好攻击最多的2只宝可梦。
  • 攻击面属性：队伍最多能打出效果绝佳的属性，以及最多会效果不好的属性。
  • 防守面：抵抗和无效最多的2只宝可梦，以及弱点最多的2只宝可梦。
  • 防守面属性：队伍最能抵抗的属性和最弱的属性。
