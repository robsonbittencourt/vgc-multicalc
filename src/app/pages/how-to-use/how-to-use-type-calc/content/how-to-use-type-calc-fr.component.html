Le Calcul de Types montre la Couverture offensive et la Couverture défensive de toute votre équipe, pour voir où elle est forte et où elle est exposée.

Contre une autre équipe

Vos Pokémon contre les Pokémon de l’équipe finaliste de Baltimore.

Contrairement à une simple table des types, le calcul utilise les capacités et les talents de votre équipe. Il se met à jour dès que vous changez un Pokémon ou une capacité.

Deuxième équipe : maintenez Ctrl (Cmd sur Mac) et cliquez sur une autre équipe dans le widget Équipes. Les tableaux montrent alors vos Pokémon contre les Pokémon de cette équipe, au lieu de chaque type.

Deuxième équipe : dans l’onglet Équipes, faites glisser une autre équipe sur la vôtre. Les tableaux montrent alors vos Pokémon contre les Pokémon de cette équipe, au lieu de chaque type.

Les talents et objets qui changent les affinités de types sont pris en compte, comme Lévitation, Ballon, Querelleur, Brise Moule, Peau Féérique et Lyophilisation contre le type Eau.

Couverture offensive

Montre comment votre équipe touche chaque type :

  • Super efficace : les types faibles à au moins une capacité de votre équipe.
  • Chaque Pokémon : la meilleure efficacité des capacités de chacun de vos Pokémon contre chaque type.
  • Lacunes : les types que votre équipe ne peut pas toucher en neutre ou en super efficace.
La couverture offensive de l’équipe championne de Francfort.

Couverture défensive

Montre comment chaque type touche votre équipe :

  • Faiblesses : les types qui infligent des dégâts super efficaces à chacun de vos Pokémon.
  • Résistances et immunités : les types sur lesquels vos Pokémon peuvent entrer sans risque.
  • Total Faible et Total Résiste : combien de vos Pokémon sont faibles ou résistent à chaque type, pour repérer les faiblesses partagées.
La couverture défensive de l’équipe championne de Francfort.

Analyses

Un résumé de la couverture, dans l’onglet Analyses :

  • Offensive : vos deux Pokémon avec le plus de coups super efficaces, et les deux avec le plus de coups pas très efficaces.
  • Types offensifs : le type que votre équipe touche le plus en super efficace, et celui qu’elle touche le plus en pas très efficace.
  • Défensive : vos deux Pokémon avec le plus de résistances et d’immunités, et les deux avec le plus de faiblesses.
  • Types défensifs : le type auquel votre équipe résiste le plus, et celui auquel elle est la plus faible.
